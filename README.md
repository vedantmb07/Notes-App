# Notes App 📝

A simple and intuitive Notes application built to help users efficiently write, organize, and manage their daily notes.

## Features
- **Create & Edit Notes:** Quickly jot down thoughts, ideas, or reminders.
- **Delete Notes:** Remove notes you no longer need.
- **Clean Interface:** Minimalist and user-friendly design for a seamless experience.

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript / React
- **Backend:** Node.js, Express
- **Database:** LocalStorage

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.
